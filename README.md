# Triiv for Game Boy Advance (formerly Null Sector)

Zero-G arena combat for the Game Boy Advance: momentum never stops, walls bounce you back, and energy is both
your shield and your ammo. Fly duels against named rivals, survive the Gauntlet and its boss, race 20 time trials,
or jump into Free Play, with Captain Finn's flight school to teach you the ropes.

## Download

Get **Triiv.gba** from the [latest release](../../releases/latest) and open it in any GBA emulator
(mGBA, SkyEmu, Delta, RetroArch, NanoBoyAdvance) or on real hardware through a flash cart. Progress saves to the
cartridge's battery memory (32 KB SRAM).

This repository holds releases only.
